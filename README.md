# The Legacy Conclave 2026

**National Conference of Educational Institutions with 50+ Years of Service**  
*Organised by Shaheen Group of Institutions, Bidar*

---

## 🏛️ About the Conclave

**The Legacy Conclave 2026** is a landmark academic conference bringing together leadership from approximately 25 foundational educational institutions across India that have completed 50 or more years of dedicated educational service.

- **Dates**: 1st & 2nd December 2026
- **Venue**: Shaheen Knowledge City, Bidar, Karnataka, India
- **Format**: In-person National Conclave & Academic Symposium

---

## 🌟 Key Highlights & Outcomes

1. **Honouring Institutional Stewards**: Felicitating visionaries and managing societies with five or more decades of community service.
2. **Launch of LINN**: Inauguration of the **Legacy Institutions National Network (LINN)** to foster sustainable inter-institutional research, faculty exchange, and resource sharing.
3. **Leadership Keynotes & Panels**: Discussions on educational stewardship, NEP 2020 integration, academic preservation, and modern pedagogical leadership.
4. **Dedicated Speakers & Dignitaries Directory**: Comprehensive profiles of participating patrons, chancellors, founders, and school education leaders.

---

## 🛠️ Technology Stack

- **Framework**: [Vite](https://vitejs.dev/) (Multi-Page Architecture - `MPA`)
- **Languages**: HTML5, Vanilla CSS3, Modern JavaScript (ES Modules)
- **Styling**: Responsive Design, CSS Custom Properties (Design Tokens), Clean Typography (Playfair Display & Inter)
- **Scroll & Interactions**: Interactive tabbed agenda, sticky scrollspy navigation, mobile drawer menu
- **Asset Optimization**: High-resolution WebP/JPG imagery and SVG iconography

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Numair25/conference-shaheen.git

# Navigate into the project directory
cd conference-shaheen

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` to explore the live development server with HMR.

### Production Build & Preview

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

The production output will be generated inside the `dist/` folder.
